# Grapheme Tutorials

This is the end-to-end tutorial track for learning Grapheme as a product, not just as a language implementation.

If you complete this sequence, you should be able to design, run, govern, and operate real workflows.

## Curriculum

1. `01-first-value.md`
2. `02-language-core.md`
3. `03-control-flow-and-state.md`
4. `04-integrations-and-policy.md`
5. `05-debugging-and-operations.md`
6. `06-realworld-scenarios.md`
7. `07-adoption-playbook.md`
8. `08-weekly-kpi-build-along.md`
9. `09-support-triage-build-along.md`
10. `10-invoice-intake-build-along.md`

## Time Budget

- Fast path: 90 minutes
- Full path with failure-path drills: 3-4 hours

## What You Build

By the end, you will have run and adapted workflows for:

- web research decisioning,
- release orchestration,
- blue/green cutover,
- incident escalation,
- feature-flag rollout,
- weekly SQL KPI anomaly digest + email.
- daily support triage queue digest,
- invoice intake approval-routing digest.
- typed support SLA escalation lifecycle,
- multi-query web scraping digest.
