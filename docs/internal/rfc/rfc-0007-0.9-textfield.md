# PR3 — TextField + action payloads

Stacks on `cursor/rfc0007-view-if-for-3588`.

Add catalog `TextField` (change → `$value: String` payload), `invoke_action(id, payload)`, and feed search.

## Acceptance

```bash
cargo test -p grapheme-compiler --test views textfield_change
cargo test -p grapheme-sdk --test view_session textfield_change

grapheme compile examples/feed-view.gr --emit view-ir --json
grapheme session examples/feed-view.gr --mount
grapheme session examples/feed-view.gr --mount --action 'expose:LoadFeed'
grapheme session examples/feed-view.gr --mount --action 'expose:Search:{"value":"Store"}' --render FeedView
```

Build the CLI first if needed: `cargo build -p grapheme-cli` (binary at `target/debug/grapheme`).

Expected:

- View IR includes a `TextField` with `on change: Search` and `payload_params: ["value"]`.
- `--action 'expose:Search:{"value":"Store"}'` sets `query` to `"Store"`.
- Missing payload on the TextField change action fails with `requires payload param 'value'`.

## Non-goals

View-declared events / forwarding, `VirtualList`, styles, slots, grapheme-ui renderer.
