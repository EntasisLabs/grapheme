## This branch — view `if` / `for`

Target surface:

```grapheme
view FeedView on Feed {
  Column {
    if $status == "pending" { Text("Loading…") }
    if $status == "failed" { Text($failure) }
    if $status == "ready" {
      for $post in $posts key $post.id {
        Row {
          Text($post.title)
          like: Button(label: "Like") { on click: Like(id: $post.id) }
        }
      }
    }
  }
}
```

### Acceptance

- Grammar + AST for `if <expr> { elements }` and `for $item in <expr> key <expr> { elements }`
- View IR nodes for conditionals and repeats (stable keys: `…/if`, `…/for/<itemKey>/…`)
- Runtime evaluation in `StoreSession::evaluate_node` with item scope
- Example `examples/feed-view.gr` (or extended feed-headless) + tests

### Non-goals

`VirtualList`, styles, slots, TextField (PR3).
