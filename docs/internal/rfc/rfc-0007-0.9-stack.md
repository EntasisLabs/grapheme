## PR #43 — TextField + payloads

Catalog `TextField` with `change` → payload param `value`. Bindings that omit that param record it in `payload_params`. `invoke_action(id, payload)` / CLI `--action 'id:{"value":"…"}'` merge the payload. Controlled search in `examples/feed-view.gr`:

```grapheme
mutation Search($value: String) on Feed {
  apply { query: $value }
}

view FeedView on Feed {
  Column {
    search: TextField(value: $query, placeholder: "Search posts", label: "Search") {
      on change: Search
    }
    …
  }
}
```

### Acceptance

```bash
cargo test -p grapheme-sdk --test view_session textfield_change_merges_payload_into_search
grapheme session examples/feed-view.gr --mount --action 'expose:Search:{"value":"Store"}' --render FeedView
```
