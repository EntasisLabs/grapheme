## This branch — view `if` / `for` (landed)

```grapheme
view FeedView on Feed {
  Column {
    if $status == "pending" { Text("Loading…") }
    if $status == "ready" {
      for $post in $posts key $post.id {
        Row {
          Text($post.title)
          like: Button(label: "Like") { on click: Like(id: $post.id) }
        }
      }
    }
  }
}
```

Example: `examples/feed-view.gr`. Tests: `view_session::feed_view_if_for_expands_after_load`.
